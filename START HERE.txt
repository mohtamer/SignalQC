SIGNALQC
Developed by Mohamed T. Hussein & Tadahiro Kishida

PORTABLE ZIP
Extract the whole folder, then open Launch SignalQC.cmd.
Python, R and packages are included. PyCharm and MATLAB are not needed.

SOURCE DOWNLOAD / APPROVED INSTALLED RUNTIMES
Run Launch SignalQC - Installed Python and R.py with your installed Python.
Select python.exe and Rscript.exe, then click Set up and open SignalQC.
The first setup needs internet access to install packages into your user folder.

TRY THE SAMPLE
On the opening Overview screen, press Run example. The recordings, metadata and settings are already loaded.
SignalQC checks the inputs, creates a project folder and runs all three stages.
Results opens when the example finishes. Choose Compare sample results to check it.

For your own recordings, choose Use my own data.
Overview also offers Reopen last project if you previously saved a project.

The sample input, reference outputs and instructions are in test.
Read README.md for the complete guide and setup requirements.
